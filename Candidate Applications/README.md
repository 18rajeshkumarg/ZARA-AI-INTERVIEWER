# Candidate Applications

This folder is written automatically by the ZARA AI Interview site when the project folder is connected.

```
Candidates/
  candidate-000001.txt   # candidate details, interview schedule, Zoom links, status and activity
  candidate-000002.txt
Uploads/
  candidate-000001.jpg   # face photo for the matching candidate
  candidate-000002.jpg
activity.txt             # one line per application/status update
```

## Important

- The candidate does **not** need to pick this folder for every application. The site remembers the selected folder in the browser and reuses it silently.
- If folder access is unavailable (new device, revoked permission or unsupported browser), the application is still saved in the browser and no error is shown.
- On a new review device, open `#/admin`, enter the Boss passcode and use **Connect folder** once.
- Candidate `.txt` and photo files are git-ignored so personal data is not published to the public GitHub repository.
